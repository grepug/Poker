# Poker Registry Service

Private shadcn-compatible component registry for Poker UI.

## Compatibility (v0.x)

- React `19.x`
- Tailwind CSS `4.x`
- Vite `7.x`

## Run locally

```bash
cd poker-registry
npm install
npm run start
```

Default URL: `http://localhost:3022`

## Endpoints

- `GET /health`
- `GET /registry/index.json`
- `GET /registry/styles/poker-dark.json`
- `GET /registry/poker/:item.json`
- `GET /registry/files/*` (static source files)

## Build artifacts

Registry JSON and file artifacts are generated by:

```bash
npm run build:registry
```

Generated output is written to `poker-registry/registry/`.

## Source of truth

- Registry component files are generated from:
  - `poker-client/src/components/poker/*.tsx`
- This keeps app UI and registry artifacts in sync and avoids drift.
